# مشغل الوسائط الشامل (Universal Media Player)

مشغل وسائط مستقل تمامًا لنظام ويندوز، مبني بلغة بايثون، ومصمم من الأساس
ليكون متاحًا بالكامل لمستخدمي قارئات الشاشة (NVDA / JAWS) وللمستخدمين
المبصرين على حد سواء، من تطوير ونشر فريق (Omnya).

## أهم المميزات

- **استقلالية كاملة**: لا يحتاج المستخدم لتثبيت VLC أو ffmpeg أو أي برنامج
  خارجي. كل شيء (فك الترميز، تشغيل الصوت) يعمل عبر مكتبات بايثون تحتوي
  المكوّنات اللازمة بداخلها.
- **دعم قارئ الشاشة**: الواجهة مبنية بـ wxPython التي تستخدم عناصر تحكم
  ويندوز الأصلية، مما يجعل NVDA وJAWS يقرآن كل عنصر تلقائيًا. أي تغيير في
  الحالة (تشغيل، إيقاف، مستوى الصوت، الوقت) يُعلَن فورًا.
- **تحكم كامل بالكيبورد**: كل الأوامر متاحة بدون الحاجة للفأرة إطلاقًا.
- **قائمة تشغيل تلقائية**: فتح أي ملف يُحضر كل ملفات الوسائط الموجودة في
  المجلد نفسه، وينتقل تلقائيًا إلى الملف التالي عند انتهاء الملف الحالي،
  مع إمكانية التنقل يدويًا بـ Page Up / Page Down.
- **استكمال تلقائي**: يتذكر البرنامج آخر موضع تشغيل لكل ملف، وقائمة
  بالملفات الأخيرة، ومستوى الصوت المفضّل، ويستكمل منها تلقائيًا في
  المرة التالية.
- **راديو وبث مباشر**: فتح أي رابط بـ Ctrl+U (http وhttps وrtsp وغيرها)، مع
  إعلان «ما يُذاع الآن» في محطات الراديو كلما تغيّر.
- **قوائم تشغيل محفوظة**: نافذة قائمة (Ctrl+L) لإضافة ملفات من أي مجلد
  وروابط وحذفها وترتيبها، وحفظها بصيغة M3U8 (Ctrl+S)، وفتح قوائم M3U وM3U8
  وPLS مثل أي ملف.
- **معادل صوتي**: 18 نمطًا جاهزًا يتنقّل بينها Q وShift+Q، ونافذة بعشرة
  نطاقات (Ctrl+E) تُسمع تعديلاتها فورًا.
- **سجل أخطاء (log)**: يُسجَّل أي استثناء غير متوقع بالتفصيل في ملف على
  القرص (في مجلد Omnya) لتسهيل تشخيص أي مشكلة.

## التشغيل في بيئة التطوير

```bash
pip install -r requirements.txt
python main.py
```

مكتبة VLC بتتحمّل من `resources/vlc/` (جهّزها بـ `download_vlc.ps1`)،
ولو مش موجودة هناك لازم يكون VLC متثبت على الجهاز.

## الاختبارات

```bash
pip install pytest
python -m pytest
```

ملفات الوسائط اللي الاختبارات محتاجاها بتتولّد تلقائيًا بـ PyAV، فمش
محتاج ffmpeg. واختبارات المحرك بتشتغل لما مكتبة VLC تكون متاحة، ولو
مش متاحة بتتخطى (skip).

## الإصدار

رقم الإصدار مصدره `core/version.py`، وبيانات الـ exe بتتقري منه وقت
البناء. رقم المثبّت (`MyAppVersion` في `omnya_player_installer.iss`)
لازم يتغيّر معاه يدويًا، والاختبار `tests/test_version.py` بيفشل لو
اتنسى.
